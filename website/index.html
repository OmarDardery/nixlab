01 / GET IT RUNNING

One command.
A reasonable number of opinions.

Run on an installed Intel/AMD x86_64 NixOS system with Internet access and hardware virtualization enabled. Start with a minimal NixOS installation; Nixlab configures the stack on top.

host / terminal
sudo nix --extra-experimental-features 'nix-command flakes' \
  run github:OmarDardery/nixlab#install
↳ Interrupted? Run the same command again. It remembers.

Your system stays your system. Installed users, boot configuration, mounts and addressing are preserved. Password SSH works for non-root Linux accounts; the installer provisions a stable operator password if needed.

Already running Incus? Review the adoption inventory and backups before proceeding. Keeping existing guests is a feature, not an exercise for the reader. Adoption details →

04 / FAIR QUESTIONS

Before you commit.

Is this a Proxmox replacement?+

It is a single-host NixOS platform built on Incus, with different trade-offs and a release-candidate status. Read the architecture and migration guide before replacing a working host.

Does it wipe my disks?+

The single-command installer does not format disks. It preserves the installed system and uses a directory storage pool by default. Existing Incus state needs explicit adoption and backups.

Why does my server need an SSH key?+

It does not need one for the default installation. Non-root Linux password login is enabled. Keys are optional client identities for remote administration; generating a server key will not let your laptop log in.

Can I close the laptop lid?+

The installer enables lid-closed operation, and the host configuration disables suspend and hibernation. Check cooling, power and battery behavior on your actual hardware. It remains a laptop, despite the promotion.
